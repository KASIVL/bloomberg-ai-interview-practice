YOUR FIRST ROUND

How to get started

Pick a challenge and work through it at your own pace.

  1. 01

    Clone the repository

    Get a copy of the starter code on your computer.

    git clone https://github.com/KASIVL/bloomberg-ai-interview-practice.git

    Don’t have Git installed? Download the ZIP, extract it, and open your chosen exercise folder in VS Code.

    Download ZIP ↓
  2. 02

    Choose your challenge

    Pick any of the five Round 1 pull requests or any of the four Round 2 engineering tickets. You don’t need to choose the presenter’s demo.

  3. 03

    Read the assignment

    Open its portal page in your browser or phone, then open only the matching exercise folder in VS Code. This keeps the assignment outside the AI helper’s normal workspace, though it doesn’t guarantee the helper can’t access it.

  4. 04

    Debug with AI

    Run the Python command, inspect the code and tests, and ask AI for explanations or hints. Make fixes yourself and rerun tests; some assertions are incorrect or meaningless, so passing tests alone doesn’t prove the code is right.

✓

BEFORE THE ROUND

Check your setup

You’ll need Python 3 and VS Code or another code editor. The exercises use Python’s standard library.

macOS / Linux python3 --versionWindows python --version or py --version

Only one working Python 3 command is needed. If the command doesn’t work, ask an officer for help before the practice round begins.
