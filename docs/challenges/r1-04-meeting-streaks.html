Meeting Streaks

PR #04
OPENREVIEW REQUIREDPYTHON

PR: Show each member’s longest meeting streak

Summary

This change adds a longest_streak helper so Cappy Hub can show members their longest run of consecutive weekly CIC meetings attended. Weeks are numbered 1, 2, 3, and so on through the semester.

Expected behavior

  • A streak is a run of consecutive week numbers; a missing week ends the streak.
  • Attending no meetings is a streak of 0, and a single meeting is a streak of 1.
  • Attendance comes from QR scans, so weeks may arrive in any order and the same week may appear more than once; a repeated week counts once.
  • The longest streak counts wherever it appears in the semester, including at the end.
  • The function must not change the list it is given.

Review task

Review the implementation and tests against the streak rules. Try inputs the tests don’t cover, check whether each assertion is actually right, then correct the implementation and the misleading tests and add regression coverage.
