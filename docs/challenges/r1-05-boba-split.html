PR: Split the boba run bill

Summary

This change adds a split_bill helper for officer boba runs. Given the total in cents, the number of people, and an optional tip percentage, it returns how many cents each person owes.

Expected behavior

  • All amounts are whole cents. The tip is added to the total first and rounded down to a whole cent.
  • The shares always add up to exactly the total with tip: no cent is lost or invented.
  • Shares differ from each other by at most one cent.
  • Zero or negative people, a negative total, or a negative tip is rejected by returning None; it must never crash.

Review task

Review the implementation and tests against the billing rules. Try a total that doesn’t divide evenly, check whether each test proves what its name claims, then correct the implementation and tests and add regression coverage.
