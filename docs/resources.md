# Further learning

- [Python `unittest` documentation](https://docs.python.org/3/library/unittest.html) — standard-library test cases, assertions, and test discovery.
- [GitHub Copilot prompt engineering](https://docs.github.com/en/copilot/concepts/prompting/prompt-engineering) — ways to give Copilot useful context and focused requests.
- [GitHub Copilot: explore a codebase](https://docs.github.com/en/copilot/tutorials/explore-a-codebase) — codebase exploration guidance.
- [Martin Fowler: Test-Driven Development](https://martinfowler.com/bliki/TestDrivenDevelopment.html) — a concise overview of the red-green-refactor loop.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) — an open collection of system design concepts and study resources.
